# Metadata Description
This repository includes two CSV files containing sample metadata for colorectal cancer microbiome studies from Sri Lanka, Kenya, and the USA.

1. DADA2_Metadata.csv: Contains the combined metadata for all three countries, including available sample identifiers, demographic characteristics, clinical conditions, and sequencing information.

2. USA_Metadata.csv: Contains only the USA sample metadata extracted from metadata.csv. This file was used for the paired Wilcoxon signed-rank test comparing CRC samples with matched normal-adjacent control samples from the same patients.

# Data sources
The metadata were compiled from the NCBI Sequence Read Archive (SRA), the European Nucleotide Archive (ENA), and corresponding BioProject records.
